# RIFT RUNNERS — Showcase

- 팀 프로젝트 RIFT RUNNERS에서 담당한 구현 코드와 기술문서, 문제 해결 과정을 정리한 개인 포트폴리오입니다.
- 외부 게임 리소스와 전체 실행 프로젝트는 포함하지 않습니다.
- 공동 구현 파일은 본인 담당 부분을 발췌하고 기여 범위를 명시합니다.

## 프로젝트 소개

- Unreal Engine 5.8.1 기반의 3인칭 협동 슈터 프로젝트입니다.
- 게임 장르: 로그라이크 · 소울라이크
- 개발 인원: 4명
- 개발 기간: 2026.08.07 ~ 2026.10.14
- 담당자: 최우석 (`seok0317`)
- 주요 담당 영역: 플레이어 · 환경 시스템

## 담당 역할

**플레이어 조작 및 전투**
- 이동·달리기·앉기·조준·회피와 카메라·애니메이션 연동
- 총구 방향 기반 에임 오프셋 보정 및 근거리 조준 떨림 개선
- 스태미나·피격 반응, 플레이어 사망 처리 확장 및 협동 부활

**눈 변형 및 혹한 환경**
- Render Target 기반 실시간 눈 변형 V1·V2 구현
- 핑퐁 RT를 통한 흔적 보존 및 Max 기반 깊이 병합
- 클라이언트 로컬 렌더링, Nanite·거리 감쇠·워밍업을 통한 처리 개선
- 눈보라 디버프·상태 회복 및 혹한 맵 제작

**로프·강풍 및 점프맵**
- 단진자 기반 캐릭터 스윙과 베를레 적분 기반 로프 표현
- 로프 손 IK, 강풍 구역 및 방향 전환 스위치
- 체크포인트·낙사 페널티 및 인원별 코스 구성
- 점프맵 배치·등록을 위한 에디터 도구

**UI·오디오·사용자 설정**
- 체력·스태미나·부활·피격 UI
- FMOD 이벤트 기반 음악 전환 및 볼륨 설정
- 홀드·토글 조작 방식과 마우스 감도 설정·저장

## 기술 스택

Unreal Engine 5.8.1, C++, Blueprint, Gameplay Ability System, FMOD

## 코드 및 기술문서 안내

- 기능별 폴더에서 담당 코드와 관련 기술문서를 확인할 수 있습니다.
- 발췌 코드는 원본 파일과 담당 구현 범위를 함께 표기합니다.
- 외부 리소스와 공용 시스템 일부가 제외되어 있어, 본 저장소만으로 게임을 빌드하거나 실행할 수 없습니다.
